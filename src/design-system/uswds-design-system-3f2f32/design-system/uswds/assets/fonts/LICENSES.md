# Font licenses

These font files are bundled by Vite and served from the app's own `/assets/`
path. They do not require a runtime request to a third-party font service.

The bundled families and versions are:

- Public Sans 2.001, including SemiBold: [SIL Open Font License
  1.1](https://github.com/uswds/public-sans/blob/develop/OFL.txt)
- Merriweather: [SIL Open Font License
  1.1](https://github.com/SorkinType/Merriweather/blob/master/OFL.txt)
- Roboto Mono 2.000985 (2015): [Apache License
  2.0](https://www.apache.org/licenses/LICENSE-2.0)
- Source Sans Pro 2.045: [SIL Open Font License
  1.1](https://github.com/adobe-fonts/source-sans/blob/release/LICENSE.md)

Source Sans 3 was present only in the removed Google Fonts request. The app's
CSS has always referenced the locally bundled Source Sans Pro family.
