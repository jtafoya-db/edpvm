Circular radio for mutually-exclusive options. Give all radios in a group the same `name`.

```jsx
<Radio label="By email" name="contact" defaultChecked />
<Radio label="By mail" name="contact" />
```

20px circle, 2px base-dark border, fills with primary blue + white dot when selected. Use for 2–5 short, exclusive options; use a Select for longer lists.
