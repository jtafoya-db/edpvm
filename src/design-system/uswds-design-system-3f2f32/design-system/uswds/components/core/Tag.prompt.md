Small uppercase tag/pill for status, metadata, or categories.

```jsx
<Tag color="primary">New</Tag>
<Tag color="accent-warm" size="big">In review</Tag>
```

Colors map to theme tokens (`base`, `primary`, `secondary`, `accent-cool/warm`, `success`, `light`). Default size is compact (10px); `big` is 14px. Keep labels to one or two words.
