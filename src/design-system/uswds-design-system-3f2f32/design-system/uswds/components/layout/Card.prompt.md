Bordered content container with optional media, serif heading, body, and footer.

```jsx
<Card heading="Get a passport" media="/photo.jpg" footer={<Button>Learn more</Button>}>
  Apply for or renew a U.S. passport for travel abroad.
</Card>
```

Flat by default — 1px hairline border + 8px radius, white surface. Headings render in Merriweather. Compose Buttons/Tags in the footer. Use in responsive grids (e.g. a Collection of cards). Avoid heavy shadows and colored left-border accents.
